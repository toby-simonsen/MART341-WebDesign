## How do web browsers function? How do web browsers really work behind the scenes?
Web browsers retrieve content from the web (such as HTML, CSS, and JavaScript files) via HTTP requests to a server. They then interpret and render the content into a visual representation that users can interact with. Behind the scenes, the browser parses HTML to build the Document Object Model (DOM) and uses a rendering engine to display the page.

## What is the DOM (Document Object Model), and how does it power your web pages?
The DOM is a tree-like structure representing the content and elements of a webpage. It allows programming languages, like JavaScript, to interact with and manipulate the structure, style, and content of the webpage dynamically.

## HTML, XML, XHTML—what sets them apart?
- **HTML (HyperText Markup Language):** A standard language for creating web pages. It is flexible and forgiving of errors.
- **XML (eXtensible Markup Language):** A stricter markup language used for storing and transporting data. It requires proper nesting and syntax.
- **XHTML (eXtensible HyperText Markup Language):** A hybrid of HTML and XML. It combines HTML’s functionality with XML’s strict syntax rules.

## What are the four essential elements every HTML page needs?
1. **`<!DOCTYPE html>`**: Declares the document type and version of HTML.
2. **`<html>`**: The root element containing all other HTML elements.
3. **`<head>`**: Contains metadata, links to stylesheets, and other non-visible data.
4. **`<body>`**: Contains the visible content of the webpage.

## What’s the purpose of the index.html page, and where should it be placed?
The `index.html` page is the default file served when a user accesses a website’s directory. It should be placed in the root folder of the website or project so it is automatically loaded when the directory is accessed.

## Review: What are the top naming practices for clean and organized code?
1. Use lowercase letters for file and folder names.
2. Avoid spaces; use hyphens or underscores instead.
3. Choose descriptive and meaningful names.
4. Maintain consistent naming conventions throughout the project.
5. Avoid special characters that may cause issues.
